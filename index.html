    # Repository Language

    Star gains are stars now minus stars N days ago, net of removed stars. ≈ marks a value computed from GitHub's star history until enough daily snapshots exist; — marks a gain not known yet, usually of a recently added repository whose star history is not read yet. Filters keep GitHub's meaning: created compares the UTC creation date, bounds are inclusive, and unknown values never match a bound. Repository details from the GitHub API.
